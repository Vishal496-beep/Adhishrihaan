# Adhishrihaan Foundation - Homepage Replica

A fully responsive, static replica of the **Adhishrihaan Foundation** homepage (`adhishrihaan.org`), built as a technical assessment using **Bootstrap 5**, **HTML5**, **CSS3**, and **JavaScript**.

## 🛠️ Tech Stack Used

---

## 📋 Features Implemented
* **Responsive Navigation Bar:** Features the foundation logo, full dropdown menus (*Events*, *Get Involved*), and a mobile-optimized collapsible toggle bar.
* **Hero Carousel Banner:** Full-width interactive sliding banner showcasing organizational pillars (*Environment*, *Animal Welfare*, *Education*) with responsive action buttons (*Know More*, *Volunteer*, *Donate*).
* **Mission & Impact Section:** Styled content blocks outlining grassroots community support and core organizational mission statements.
* **Focus Areas Gallery:** An asymmetric photo grid gallery highlighting various community initiatives (*Woman and Child Welfare*, *Healthcare*, *Skill Development*, etc.) with hover zoom effects and dark gradient text overlays.
* **Grant & Initiatives Section:** Dual-column responsive layout detailing *The Shrihaan Sahyog Grant*.
* **Interactive Events Section:** Responsive card carousel and tabbed filter layout showcasing past and upcoming community events with detailed metadata tags.
* **Comprehensive Footer:** Dark green gradient footer complete with contact details, social media icon links, a "Donate Now" call-to-action button, copyright information, and quick navigation links.
